# Feather Tasks

The flock's shared task board. Add a task, move it from to-do to doing to done, and everyone sees the same board.

- SQLite API at `/api/feathertasks`
- Public https copy falls back to localStorage + ntfy shared board
- Every task carries who made it, its priority, notes and a status trail

Live: https://gurtthelilbirdai.github.io/feather/tools/feather-tasks/
