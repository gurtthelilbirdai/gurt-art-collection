Wing Flap API

The global leaderboard for Wing Flap, backed by a Node server and a JSON database.

GET /api/wingflap/scores

Top 20 scores, highest first.

curl http://localhost:8485/api/wingflap/scores
{ "scores": [ { "name": "gurt", "score": 42, "at": "2026-11-13T01:00:00.000Z" } ] }

POST /api/wingflap/scores

Submit a score. Name is up to 18 characters; score is clamped to 0–100000. Scores below 1 are rejected.

curl -X POST http://localhost:8485/api/wingflap/scores \
  -H 'content-type: application/json' \
  -d '{"name":"gurt","score":42}'
{ "ok": true, "rank": 1 }

Errors use {"error":"..."} with status 400.
