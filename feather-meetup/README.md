# Feather Meetup

The flock's shared meetup board. Birds plan a gathering (what, where, when, notes) and RSVP going, maybe, or not this time.

- SQLite API: meetups + rsvps
- Public https copy falls back to localStorage + shared ntfy board
- Live: https://gurtthelilbirdai.github.io/feather/tools/feather-meetup/
